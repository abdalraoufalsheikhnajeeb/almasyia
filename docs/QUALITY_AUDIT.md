# مراجعة جودة الموقع — 2026-09-27

## التحسينات المنفذة

- تحديث Next.js إلى 16.3.6 وReact إلى 19.3.0 وSharp إلى 0.35.5،
  وتحديث الاعتماديات المتوافقة وملف القفل وحذف إضافات تطوير غير مستخدمة.
- توطين عنوان ووصف الصفحة الرئيسية للعربية والإنجليزية والروسية، مع التركيز
  على السفر بين دمشق ودبي ونقل الوثائق واسم النجوم الماسية وفاروق دكاك.
- توحيد canonical وhreflang وإضافة x-default، وتصحيح روابط وصور المشاركة.
- إضافة بدائل اللغات لكل صفحة في sitemap، وعدم اختلاق تواريخ تعديل عند البناء.
- تحويل دائم 308 من مسار ChamWingsAirlines القديم إلى FlyChamAirlines.
- تصحيح مخطط الخدمات والمؤسس، وحذف serviceOffer غير الصحيح وتقييمات
  LocalBusiness الذاتية من JSON-LD؛ التعليقات المرئية بقيت كما كانت.
- إضافة إرشادات بثلاث لغات لطلب السفر ونقل الوثائق وروابط للخدمات المتعلقة،
  دون اختلاق أسعار أو ضمانات للتأشيرة أو مواعيد التسليم.
- توفير main واحد لكل صفحة، ورابط تخطي قابل للتركيز، وتصحيح ترتيب العناوين
  والعناوين الفارغة والروابط الخالية.
- تحسين تشغيل القوائم بلوحة المفاتيح وإغلاقها بـ Escape، وتصحيح دلالات
  اختيار اللغة. قائمة التنقل على الهاتف تغلق بعد اختيار الرابط.
- إيقاف الدوران التلقائي للمعارض وإضافة أزرار تنقل قابلة للوصول، وتكبير
  أهداف اللمس وإزالة حركات زخرفية مستمرة.
- إصلاح تباين النص الذهبي وعناوين الجداول، وإتاحة تمرير الجداول بلوحة
  المفاتيح، وإصلاح تجاوز عرض الشاشة على الهاتف.
- إصلاح مسارات صور إندونيسيا وتايلاند وصور مشاركة طيران قطر وبيغاسوس،
  وإضافة sizes للصور المتجاوبة والسماح بقيم الجودة المستخدمة فعلياً.
- نقل صورة المشاركة من مسار metadata التلقائي إلى public بنفس محتواها
  ورابطها، لإزالة تحذير metadataBase أثناء البناء.
- استخدام font-display: optional لتجنب تبديل الخط المتأخر على الشبكات البطيئة.
  قد يظهر الخط البديل في الزيارة الأولى إذا تأخر تحميل خط الموقع.
- منع التخزين المشترك لتحويل اللغة المعتمد على Cookie/Accept-Language.
- حماية النوافذ الخارجية للنماذج بـ noopener,noreferrer وإظهار تنبيه
  واضح لمشاركة البيانات عبر WhatsApp أو Formspree.
- إضافة أمر audit:site قابل لإعادة التشغيل وشرح خطوات الفحص في README.

## نطاق الفحص

البناء محلي بنمط الإنتاج على Windows/Chrome وNode.js 25.9.0، وليس قياساً
للنشر العام على Vercel. يفضّل استخدام Node LTS مدعوم في بيئة النشر.

## نتائج إعادة الاختبار

- نجح npm run lint دون تحذيرات، وnpm run typecheck، وnpm run build
  بما يشمل TypeScript وتوليد الصفحات وsitemap.
- npm audit: لا ثغرات معروفة في الاعتماديات وقت الفحص.
- npm run audit:site: اجتازت 144 صفحة، و319 مسار صورة، و144 رابطاً
  داخلياً. اجتازت اختبارات اللغات والتحويل 308 وصفحة 404 ومحسّن الصور.
- Playwright وaxe: اجتازت 29 حالة تغطي اللغات الثلاث، الصفحات الرئيسية،
  الخدمات والنماذج والبلدان والتعريف والتواصل والساعة وبرامج السياحة والطيران،
  مع عينات للوضع الداكن وسطح المكتب. لا مخالفات آلية أو تجاوز أفقي
  في الحالات المختبرة، ولا أخطاء JavaScript مسجلة.
- نجحت تجربة إغلاق قائمة الهاتف بعد الضغط، وإغلاق قوائم اللغة والاتصال
  والمظهر بـ Escape، وحفظ تفضيل المظهر، ومزامنة تاريخ العودة، وإنشاء طلب WhatsApp باستخدام بديل
  محلي لـ window.open، وإرسال نموذج التواصل واستعادة حالته عبر استجابة
  Formspree محاكاة. لم تُرسل رسائل أو بيانات حقيقية إلى الخارج.
- نجح git diff --check. بقيت صورة المستخدم غير المتتبعة دون تعديل.

## ما يحتاج متابعة بعد النشر

1. إعادة PageSpeed Insights للعربية والإنجليزية من النطاق الفعلي؛ درجة
   Lighthouse المحلية ليست ضماناً لدرجة الإنتاج أو Core Web Vitals الميدانية.
2. إرسال sitemap في Google Search Console وفحص canonical وبدائل اللغات،
   ثم متابعة الصفحات المفهرسة والاستعلامات والأداء الفعلي.
3. التحقق من Google Business Profile للفروع وتطابق الاسم والعنوان والهاتف.
4. مراجعة أرقام العملاء والخبرة والتقييم 5.0 والتعليقات المنقولة وتواريخها
   ومعلومات شركات الطيران والعروض والأسعار مع صاحب العمل؛ لم نتحقق من
   صحتها ميدانياً ولم نخترع بيانات جديدة.
5. اعتماد سياسة خصوصية فعلية توضّح حفظ البيانات ومقدمي الخدمة ووسيلة
   طلب الحذف. التنبيه المختصر في النماذج ليس بديلاً عن تلك السياسة.
6. تجربة يدوية بقارئ شاشة وعلى أجهزة iOS/Android حقيقية؛ الفحص الآلي
   لا يثبت الامتثال الكامل لـ WCAG.
7. إرسال طلب تجريبي مصرح به إلى WhatsApp/Formspree عند التسليم؛ اختبارات
   النماذج المحلية تحاكي الإرسال ولا ترسل رسائل حقيقية.
8. متابعة توافق ESLint 10 مع إضافة React. أبقينا ESLint 9 بعد فشل الإصدار
   10 فعلياً، وأبقينا Tailwind 3 وTypeScript 5 دون ترحيل رئيسي غير ضروري.
